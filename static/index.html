How to get help

ScamShield gives you a calm second opinion. It does not contact the sender or open links.

1. Bring the request

Paste the message, upload a screenshot, or add a supported mono WAV clip. Remove private details if you prefer.

2. Choose a language

Select the language for the report. Custom languages are passed to the configured model when supported.

3. Read the evidence

Review the risk score, red flags, static link/phone checks, and the safest next steps.

4. Verify elsewhere

Use the provider’s official app or published hotline. Never share an OTP, PIN, password, or payment.
